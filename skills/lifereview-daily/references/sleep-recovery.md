# 睡眠与恢复

先核对analysis-contract.md中的夜晚归属、数据源和HRV窗口。

- Looki出现屏幕、卧室或睡眠相关词不能证明已经睡着；入睡/起床优先用可靠睡眠记录或用户确认。不要用关键词覆盖真实活动或设备睡眠时间。
- 单晚总睡眠、深睡、快速眼动睡眠只是估算记录，结合个人趋势与覆盖解释。深睡增加不自动等于透支后维修；分期下降不等于认知能力受损。
- HRV夜内前低后高描述为具体时段变化；数据不足不命名恢复机制。静息心率偏高也不能单独诊断自主神经应激。
- 当天有已确认晚间工作、次夜睡眠变短时，可描述两者相邻发生，提出调整收尾时间的观察实验；只有日历则明确是安排时段。
- 日常建议可包括为睡眠预留时间、按实际困意调整安排、复核下一夜变化；不保证精确睡眠结果，不自动替用户取消会议或开具呼吸/饮食/药物治疗方案。
- 历史个人关联引用时附来源、样本量和时期，核对有无旅行、酒精、训练、设备变化等混杂；没有这些信息就作为待验证假设。
