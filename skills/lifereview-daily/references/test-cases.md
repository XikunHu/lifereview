# 测试用例 — 已知失败模式

每次修改 Skill 或脚本后，逐条检查以下场景。

## 1. 数据聚合

| 测试项 | 预期 | 曾失败 |
|--------|------|--------|
| 步数取 sum() | 全天汇总，非首个条目 | 6/20 显示 8 步（实际 13422） |
| 活跃能量取 sum() | 全天汇总 | 同上 |
| RHR 取 median() | 中位数抗离群 | — |
| HRV 取夜间 median() | 0-9点窗口 | 白天数据会污染恢复评估 |
| 新增指标前确认粒度 | sum/median/first 分类 | — |

## 2. 数据新鲜度

| 测试项 | 预期 | 曾失败 |

## 6. CGM 血糖 × 行为 × 状态（v4.8）

| 测试项 | 预期 | 曾失败 |
|--------|------|--------|
| `.hae` 从文件头 LZFSE 解压 | 得到 JSON，非空数据日可解析 | 把 `bvx2` 误当私有 header 后跳过导致解压失败 |
| mmol/L + mg/dL 双单位去重 | 每 5 分钟只保留一个 mmol/L 点 | 未统一单位会令均值/峰值荒谬 |
| 覆盖 <20h | 显示实际覆盖，并明确晚间结论留空 | 用半天数据评价全天 |
| Looki 描述提到食物、标题是通勤/运动 | 不建立餐次窗口 | 说明文字串场造成假餐次 |
| 明确餐食标题 | 输出餐前 30min 中位数、餐后峰及约2h值 | 只用单次 delta 比较餐次 |
| 餐后有明确运动场景 | 只记录 120min 内的已标注活动 | 未记录行为却假定饭后散步 |
| RHR/HRV/睡眠缺一项 | 仅报告血糖形态，不做血糖-状态对应 | 恢复数据缺失仍称状态稳定 |
| 血糖平稳而恢复偏离 | 写“不同步，不能归因于血糖波动” | 单日时间相关被写成因果 |

## 7. 无 Looki 模式（v5.1 · 2026-08-08）

`daily-brief-ad.py --no-looki`（或独立 `daily-brief-nolooki.py`）：

| 测试项 | 预期 | 说明 |
|--------|------|------|
| `--no-looki` 存在时 get_looki 零调用 | Looki 完全隔离 | 实测 calls=0 |
| 日历深度解读注入 | 数据段 `📅 日历 N场 Xh 跨度XX-XX 负荷` | calendar-insight.py |
| 日历可安排空档识别 | `| 没有日程的时段 N个: HH:MM-HH:MM（是否休息需结合心率/步数）` | ≥45min 空白不能直接叫恢复 |
| 生理节点×时段 | `🏋️/↗️/↘️/🪑 HH:MM + 用户可见事实` | 内部 evidence 不拼进主文案 |
| 信号显式标注 | `🚫 Looki 无数据，🆘🍬😴 信号无法提取` | 铁律，禁止沉默跳过 |
| prompt 禁编造铁律 | no-looki 时 system 含「禁止编造任何行为细节」 | 默认模式不含 |
| cal_recovery 角度 | 需 cal_insight.load_breakdown 存在才可选 | 否则 None |
| cal_phys 角度 | 需 phys_nodes.markers 非空才可选 | 否则 None |
| 默认模式零影响 | 无 --no-looki 时 NO_LOOKI=False、引擎不加载 | 回归验证 |

### 生理节点引擎（physiology-nodes.py）口径

- HR 峰值：白天 7-23 点 avg ≥ 白天中位+7 bpm（HAE 无 count，附 Max）
- 运动期间：结构化训练 或 日历标题含 训练/健身/Dosefit/力量/运动/体能/跑步/骑行 → hr_exercise
- 晨间恢复弹性：晨间(6-10点)首个读数 ≤ 夜间(22-4点)中位-15ms → 用户只写「低于夜间水平，单次记录不定性」
- 连续低活动：9-21 点步数<5 连续 ≥2h；不得仅凭它断定休息或久坐
- 日历对应：节点小时有 accept 日程 → 内部 `evidence/evidence_tier` 保存；用户只写「这一时段日历里有 XX」，不出现佐证/同窗/原因未确认

## 8. 用户文案与跨日时间归属（v5.2 · 2026-08-08）

| 测试项 | 预期 | 回归事故 |
|---|---|---|
| 活动能量单位 | HAE kJ / 4.184 → 整数 kcal | 曾把 1701.83 kJ 写成 1701.83 kcal |

| 静息心率视觉 | 普通值中性色；明确风险才红色 | 红心/红星曾让用户误读为警告 |
| 日历空白 | 没有安排；结合心率/步数才描述身体是否安静 | 禁止空白=休息/恢复 |

| 指标排版 | 每组单独换行；数值取整 | 禁止十几个指标挤一行 |
