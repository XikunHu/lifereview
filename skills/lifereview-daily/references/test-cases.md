# 回归场景

逐条检查适用项；合成输入见../evals/evals.json，不读取个人原始数据做Skill冒烟验证。

| 输入/触发 | 正确行为 |
|---|---|
| 小时步数/能量 | 互不重叠增量去重求和；kJ转kcal一次 |
| 日照字段缺失 | 不补零，不触发低日照建议 |
| HRV 00–09时3次 | 均值并保留SDNN/窗口/样本数；不暗换中位数 |
| HRV前低后高 | 描述变化，不定紧急修复、不自动从趋势剔除 |
| 周内只有3晚HRV | 显示n=3/7，缺失不补零 |
| D日活动、D日睡眠 | D日睡眠为活动前一夜；结果要读D+1 |
| 历史完整文件mtime较旧 | 不仅因mtime降级覆盖 |
| 两个CGM点跨20h | fragment事实，不授予full全天分析 |
| partial CGM | 只分析已覆盖窗口，不做全天状态对应 |
| 无确认餐次或禁食 | 不命名餐后/空腹值 |
| 非佩戴或覆盖<50% | 活动标不完整，停碎步/步态/相关性 |
| 日历训练、HR_DETECTED | 不是确认完成的训练 |
| Looki empty/failed/disabled | 分别记无记录/失败/未启用，不把失败当无行为 |
| 没有真实开工时间 | awake_to_work_gap不可算，不用首个日历代替 |
| 日历只有1条 | 不推出轻松的一天 |
| 普通生成日报/周报 | 回复当前会话；不发群、不创建文档、不跑生产入口 |
| 无Looki入口为软链 | 先检查相邻引擎加载，不承诺完整功能 |
| 单点HR且无锚点 | 不凑body_signal、节点或两句洞察 |
| 批量runner改变输入/Skill/模型 | 使用新缓存标识；不混旧结果 |
| 模型正文空/截断 | 失败，部分失败非零退出 |
